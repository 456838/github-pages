Local by design

A desktop tool with clear boundaries.

Mobile Matrix communicates with Android through the local ADB connection. Screen streaming and input are provided by the bundled STF Lite integration and runtime resources.

The current public release supports Apple Silicon macOS. Windows and Linux builds are not presented as supported until they have a validated distributable package.

No cloud control service No Docker or RethinkDB required No Android client app required

FAQ

Questions before you connect a device?

Which Mac is supported?

The current public release is built and validated for Apple Silicon Macs using the arm64 architecture.

Does Mobile Matrix control an Android phone?

Yes. It controls an authorized Android device connected through ADB, including live display, keyboard, touch, clipboard, screenshots, and device tools.

Is this the full STF server stack?

No. Mobile Matrix embeds a focused STF Lite runtime for local screen streaming and device input. It does not claim to be the full STF server stack.

Can I use Wi-Fi ADB?

The product includes ADB remote network debugging controls, but support depends on the Android device's wireless debugging mode and the configured endpoint.

Does it upload my screen to the cloud?

The public desktop workflow is local-first: the app communicates with the Android device through the local ADB connection.

Are Windows and Linux available?

Not as validated public release packages yet. The official download currently targets Apple Silicon macOS.
